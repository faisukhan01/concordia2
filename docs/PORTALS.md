# Portals

| Portal | Role | Key features |
|---|---|---|
| Admin | admin, super-admin | All modules, SubTabBar |
| Admissions | admissions | Student intake, applications |
| Accountant | accountant | Fees, invoices, receipts |
| Academic | academic | Attendance, results, timetable |
| Student | student | View-only: attendance, results, fees, timetable |

Admins see the SubTabBar to switch between sub-portal tasks. Other roles use the bottom nav footer.
