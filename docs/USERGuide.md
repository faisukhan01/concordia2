# Concordia College App - User Guide

A quick guide for students, staff, and administrators using the Concordia College mobile app.

## Roles

- **Student** - view attendance, results, timetable, fees.
- **Accountant** - manage fee records and invoices.
- **Admissions Officer** - manage student admissions.
- **Academic Staff** - manage attendance and results.
- **Admin** - full access to all portals.

## Getting Started

1. Download the APK from the releases page.
2. Sign in with your college-issued credentials.
3. Use the bottom navigation to switch between modules.
