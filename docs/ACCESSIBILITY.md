# Accessibility

## Targets

- WCAG 2.1 AA contrast ratios
- 44px minimum touch targets
- Screen-reader labels on all icons

## Implementation

- Semantic widgets: `Semantics`, `MergeSemantics`
- Sufficient color contrast (brand orange #F26522 on white = 3.4:1, use for large text only; pair with darker text for body)
- Focus traversal order verified on each screen
