# Colors

| Token | Hex | Usage |
|---|---|---|
| Primary Orange | #F26522 | CTAs, active states |
| Cream Background | #FFF6EE | Page background |
| Primary Gradient | #F26522 -> #FF8A4C | Prominent buttons |
| White | #FFFFFF | Cards |
| Ink | #1A1A1A | Body text |

Use `AppColors.primaryGradient` and `appGradient()` helper for branded CTAs.
